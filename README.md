# 🎲 Random tanlov

Davomat belgilash va o'quvchilarni hayajonli tarzda tasodifiy tanlash uchun oddiy veb-sahifa.

- Kelgan o'quvchilarni belgilash, qo'shish va o'chirish
- Nechta o'quvchi tanlanishini kiritish
- Birma-bir ruletka va "Tanlandimi...?" suspense effekti
- Ovozli effektlar (🔊 tugmasi bilan o'chirib-yoqiladi)
- Tanlanmaganlarga hamdardlik bildirish

## Ishlatish
`index.html` faylini brauzerda oching. Boshqa hech narsa o'rnatish shart emas.

## GitHub Pages
Repository → Settings → Pages → Branch: `main` / `(root)` → Save.
Bir necha daqiqadan so'ng sahifa `https://<username>.github.io/<repo>/` manzilida ochiladi.
